# 副屏媒体播放

面向 Android 6.0 / API 23 的独立应用，包名 `org.example.guangqidashboard`。只参考相邻 mirror 项目的“显示测试图”副屏建窗方式与编译流程，**不包含录屏、主屏镜像、导航激活广播、开机启动或 root 操作**。

## 功能与使用

1. 安装 `dist/` 中的 APK，打开“副屏媒体播放”。
2. 点击“选择媒体”，在支持的文件管理器（例如 RE）或媒体管理器（例如快图）中选择图片、GIF、视频。管理器支持多选时可批量导入，通常需要先长按一个文件。
3. 如果第三方管理器不支持该入口，使用“系统文档选择器”备用按钮。文件管理器返回 `file://` 时，Android 6 会申请读取存储权限；系统文档选择器返回带读取授权的 `content://` 时不要求全盘读取权限。
4. 文件追加到现有列表，按选择器返回的顺序排列。**返回顺序不一定是点击顺序**；通过“上移 / 下移”调整，播放时严格遵循当前列表顺序。移除 / 清空只删除应用内部副本，不修改源文件。
5. 刷新并选择目标副屏，主屏（Display 0）始终被排除。
6. 选择窗口模式：先尝试标准 Presentation；若车机不显示，可授权悬浮窗后尝试“广汽兼容 TYPE_PHONE / 2002”或“腾讯兼容 TYPE_SYSTEM_ALERT / 2003”。这些模式与 mirror 测试图相同，但不保证所有车机都允许显示。
7. 设置图片 / GIF 停留时间（5 / 10 / 15 / 30 / 60 秒），选择是否循环，点击“开始播放”，确认车辆已经停稳。
8. 视频播完自动切换，图片 / GIF 按所设时间切换。GIF 在停留期间循环动画。可手动下一项或停止。

主屏只有选择、配置、播放控制和带播放位置标记的文件列表，不创建图片预览或视频画面。副屏为黑色全屏背景，媒体保持比例、居中显示，比例不同时会留黑边，不裁剪拉伸。视频使用系统播放器，音轨按车机系统的音频路由播放，不承诺副屏独立音频。

修改列表会停止播放，重新开始时从第一项播放。离开应用 / 锁屏导致 Activity 停止、目标副屏断开或关闭、关闭应用时释放播放器和副屏窗口，不在后台继续播放。列表和成功导入的内部副本保留，重新打开后可手动播放；不自动播放。

> 仅供停车测试。副屏窗口可能遮挡车速、告警等仪表信息；禁止行车观看或操作。此项目不继承 mirror 测试图的 60 秒自动关闭，而是由播放模式、手动停止和前台生命周期控制结束。

## 格式、内存与存储

- 视频：交给 Android 6 系统解码器，实际支持的容器、编码、分辨率依赖车机。优先使用 MP4 / H.264 AVC + AAC；HEVC、AV1、新编码或过高分辨率不保证可播。
- 静态图：使用系统 Bitmap 解码器并降采样，控制解码像素以适应 32 位内存环境。格式支持依赖系统，不支持的图片会跳过。
- GIF：使用 Android 6 自带 `Movie` 动画解码，软件画布绘制；解码前扫描 GIF 数据块，限制输入 20 MiB、单边 2048、画布 200 万像素、最多 500 帧、累计帧像素 1600 万，避免小体积长动画耗尽原生内存。超限时请缩小动画或转成视频。设备剩余内存仍影响解码，会尝试捕获解码内存不足并跳过，不能保证设备一定能解码所有 GIF。其他格式的动画不承诺动画播放。
- 单个文件无法读取 / 解码时显示提示并跳过；连续失败达到列表长度后终止，防止全坏文件无限循环。视频准备超过 30 秒会跳过。
- 导入会将文件复制到应用私有存储，因此大视频导入需要时间和等量内部空间。复制时至少保留 32 MiB 空间，不修改源文件；临时读取授权失效或源文件之后被移走不会影响已成功导入的副本。
- 复制在工作线程中进行；导入期间不可开始播放或修改列表。若导入中进程被回收，下次启动成功读取已保存列表后会清理未登记的内部副本和半成品；列表损坏时不盲目删除文件。不支持通过网络 URL 播放，不申请联网权限。
- 没有第三方播放器依赖或原生 `.so`，APK 与 CPU ABI 无关，可安装到 32 位 ARM Android 6 设备。系统自身的硬件 / 软件解码能力仍是限制。

## 编译

沿用 mirror 的轻量工具链，不要求 Gradle / Android Studio：

- JDK（支持 `javac --release 8`，脚本优先使用 `JAVA_HOME` 或 Homebrew OpenJDK）
- `apktool`（本机编译验证版本 3.0.3）
- 默认复用 `../mirror/.tools/android-23/android.jar` 与 `../mirror/.tools/r8-8.3.37/r8.jar`
- Python 3

```bash
bash guangqi-dashboard-media/build.sh
```

也可显式设置 `ANDROID_JAR` / `D8_JAR` 使用独立工具链；不复制或修改 mirror 源码及签名密钥。输出在 `dist/guangqi-dashboard-media-media-0.1.0-debug-<时间戳>.apk`，使用本项目 `.keys/debug.p12` 的本地调试密钥签名，支持 Android 6 的 v1 签名。自签名证书 / 无时间戳的 jarsigner 警告是本地调试构建的预期警告，不是签名验证失败。分发正式版前应改用正式保管的签名密钥。

`minSdkVersion` / `targetSdkVersion` 均为 23，编译与 DEX 最低 API 均为 23。保留本项目 `.keys/` 可以在后续调试 APK 间覆盖升级。

## 验证

构建脚本自动运行：

- 纯 Java 播放顺序测试：单次播放、循环、单文件循环、跳过失败、全坏文件停止、成功后清除连续失败计数、拒绝空列表。
- GIF 解码前扫描测试：有效帧结构、帧数 / 累计像素预算、画布尺寸、截断、错误文件头和越界帧。
- 中断导入清理测试：保留已登记副本，删除未登记副本和半成品，不影响无关文件或子目录。
- 完整源码针对 Android API 23 编译。
- APK v1 签名验证、ZIP 完整性检查、DEX 035 与无原生 ABI 依赖检查。
- 反解成品清单，验证包名、API 23 最低 / 目标版本、启动入口、权限及无后台组件。

单独运行逻辑测试：

```bash
bash guangqi-dashboard-media/tests/run.sh
```

当前环境没有 `adb` 或连接的车机，**尚未真机验证副屏可见性与解码效果**。建议停车后逐项验证：

- RE / 快图单选、多选；系统选择器混合图片 / GIF / 视频；取消选择。
- 首次存储权限允许 / 拒绝，文件名含中文，重新打开应用后列表保留。
- 纯图片、纯视频、纯 GIF、混合列表：顺序、留黑边、GIF 动画、视频自动切换、循环与单次停止。
- 上移 / 下移 / 移除 / 清空不影响原文件，主屏始终没有媒体画面。
- 无副屏、三个窗口模式、悬浮窗权限拒绝、副屏拔除 / 熄灭、返回桌面后确实关闭副屏。
- 损坏文件、不受支持的视频编码、过大 GIF、内部空间不足时的提示和跳过 / 终止。
